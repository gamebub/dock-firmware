# Game Bub Dock Firmware

This repository contains firmware for the [Game Bub Dock](https://gamebub.net/), which can be purchased [on Crowd Supply](https://www.crowdsupply.com/second-bedroom/game-bub#products).

Please see the [Game Bub Documentation](https://docs.gamebub.net/) for more information.
